# 兰玉晗 · 个人作品集

一个沉浸式滚动叙事作品集网站，包含：

- 首页玻璃砖墙与手写签名开场
- 滚动穿越的作品章节
- 2 张展板作品：《水巷寻游》《巷陌寻踪 · 漫游平江》
- 2 支广告剪辑作品：《新希望》《爷爷不泡茶》
- 视频点击全屏播放，带声音与原生控制条
- 星树、许愿瓶与夜间联系页结尾

## 本地预览

双击 `启动作品集.bat`，浏览器会自动打开：

```text
http://127.0.0.1:8137/index.html
```

也可以手动启动：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\serve.ps1 -Port 8137 -Open
```

## GitHub Pages

本仓库是纯静态站点，`index.html` 位于仓库根目录。开启 GitHub Pages 时选择：

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/ (root)`
